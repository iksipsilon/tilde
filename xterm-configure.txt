Set-up in ~/.Xresources

Note, that you can set this up as either XTerm*faceName if you want any application that uses that X class to use the setting, or xterm*faceName which is the instance of XTerm.

xterm*faceName: OCRA
xterm*faceSize: 18
xterm*renderFont: true


Merge .Xresources and check

Merge and then to double check use appres or xrdb -query

$ xrdb -merge .Xresources
